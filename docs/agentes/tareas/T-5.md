# T-5 — Instalar telemetria-ia como skill de Claude Code y Codex

**Contexto:** el equipo quiere preguntarle a la IA "¿cuánto consumí?" en vez de buscar la carpeta del proyecto. La
skill ya está escrita en `skill/SKILL.md` (plantilla con `{{RAIZ}}`); falta instalarla.
**Archivos permitidos:** `instalar-skill.js` (nuevo, en la raíz), `test/instalar-skill.test.js` (nuevo), `README.md`,
`package.json` (solo agregar `"skill/"` si hiciera falta en algún campo; no agregues dependencias),
`docs/agentes/reportes/T-5.md` (nada fuera de aquí; **no cambies `skill/SKILL.md`**)
**Depende de:** `skill/SKILL.md`
**Agente / modelo:** codex
**Modo:** escritura

## Objetivo

`node instalar-skill.js` instala la skill `telemetria` en Claude Code y en Codex apuntando a la carpeta donde está
clonado el repo, para que la IA corra `node "<repo>/bin/telemetria.js" ...` desde cualquier proyecto.

## Contrato (no cambiarlo)

`node instalar-skill.js [--claude] [--codex] [--quitar]`

- Destinos (`home` = `process.env.TELEMETRIA_HOME || os.homedir()`):
  - Claude Code: `${CLAUDE_CONFIG_DIR:-home/.claude}/skills/telemetria/SKILL.md`
  - Codex: `${CODEX_HOME:-home/.codex}/skills/telemetria/SKILL.md` y
    `${CODEX_HOME:-home/.codex}/skills/telemetria/agents/openai.yaml` con:
    ```yaml
    interface:
      display_name: "Telemetría de IA"
      short_description: "Consumo de IA de la PC por modelo, effort, herramienta y proyecto"
      default_prompt: "Usa $telemetria para mostrar mi consumo de IA de esta semana."
    policy:
      allow_implicit_invocation: true
    ```
- Sin `--claude` ni `--codex`: instala en cada uno cuya carpeta base (`~/.claude` o `~/.codex`, o la de su variable)
  exista; si no existe ninguna, lo dice y sale con 2. Con la opción, instala en ese aunque la carpeta no exista
  (la crea).
- `SKILL.md` instalado = `skill/SKILL.md` con `{{RAIZ}}` reemplazado por la ruta absoluta del repo (la carpeta de
  `instalar-skill.js`) con `/` como separador (también en Windows: `D:/a/telemetria-ia`), para que funcione igual en
  PowerShell, CMD y bash.
- Marca de propiedad: escribe `.origen-telemetria-ia` en cada carpeta `telemetria` que instala. Si ya existe una
  carpeta `telemetria` **sin** esa marca, no la toca: avisa y sigue con el otro destino (código 1 al final).
- Se puede correr varias veces (después de `git pull`, para actualizar la skill): reemplaza solo lo suyo.
- `--quitar`: borra solo las carpetas `telemetria` que tienen la marca (en los destinos elegidos o en ambos).
- Imprime una línea por destino (`Claude Code: instalada en <ruta>` / `Codex: ...` / `omitida: ...`) y al final cómo
  usarla: en Claude Code `/telemetria` o preguntar "¿cuánto consumí esta semana?"; en Codex `$telemetria` o preguntar
  lo mismo. Si Codex o Claude Code estaban abiertos, hay que abrir una sesión nueva para que la vean.
- Solo Node estándar (`fs`, `path`, `os`). Sin dependencias.

### README.md

Agrega después de "Actualizar o quitar" una sección **"Usarlo como skill (preguntarle a la IA)"**, corta:
- para qué sirve (no buscar la carpeta: le preguntas a Claude Code o a Codex desde cualquier proyecto);
- `node instalar-skill.js` (y `--claude`, `--codex`, `--quitar`), y que después de `git pull` se vuelve a correr;
- cómo se pide: `/telemetria` en Claude Code, `$telemetria` en Codex, o preguntar "¿cuánto consumí esta semana?",
  "¿qué modelo uso más?", "¿cuánto consumió el proyecto X?";
- que así **sí** se gastan unos pocos tokens (la IA corre el comando y lee una vista corta); el comando en la terminal
  sigue siendo gratis. Ajusta la pregunta frecuente "¿El reporte consume tokens?" para que diga lo mismo.
